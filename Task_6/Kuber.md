# Подготовленное приложение развернуть в Kubernetes  

1. Подготовить 3 манифеста для deploy, внутреннего доступа и внешнего доступа.  
Для деплоя:  
    Указать колличество реплик, образ, с которого развернётся приложение, нужный нам порт (80), указать лимит ресурсов.  
Для внутреннего доступа:  
    Указать приложение, и source и destination порты.  
Для внешнего доступа:  
    Прописать хост и порт и т.д.  

2. Применить манифесты через команду: kubectl apply.  

3. Проверить статус подов и развёртывания через kubectl get.
