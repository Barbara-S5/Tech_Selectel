# Диагностика недоступности NGINX  

1. Первое, что надо сделать, это попробовать перезапустить сервис: systemctl reload nginx.   
2. Если это не помогло, то узнать промежуток времени с которого начались проблемы с доступности сервиса.  
3. Следующее, стоит залезть в логи nginx - /var/log/nginx/error.log:    
Обычно, в логах всё видно, это может быть: просроченный SSL-сертификат, переполненое число подключений, неспособность подключения к бэкенду, нет нужного файла.  

4. Если в логах ничего не видно, можно посмотреть не занят ли нужный порт: lsof -i :80 и lsof -i :443.
